# @luna/web — 루나 사이트

Astro 정적 사이트. 빌드할 때만 Postgres를 읽고, 방문자 요청은 DB·Notion에 닿지 않는다.

## 로컬 실행

```bash
pnpm install
pnpm dev                 # DATABASE_URL이 없으면 목업 데이터로 뜬다
pnpm --filter @luna/web build && pnpm --filter @luna/web preview
```

| 환경 변수          | 설명                                                                                                                              |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `LUNA_DATA_SOURCE` | `db` 또는 `mock`. 비우면 `DATABASE_URL`이 있을 때 db, 없을 때 mock. CI에서 둘 다 없으면 빌드를 멈춘다(목업이 배포되는 사고 방지). |
| `DATABASE_URL`     | 빌드 시 읽을 Postgres                                                                                                             |
| `R2_PUBLIC_URL`    | 사진 주소의 앞부분. 없으면 사진 대신 자리표시를 그린다                                                                            |
| `SITE_URL`         | canonical·sitemap·OG의 절대 주소. TODO: 도메인 확정                                                                               |

목업으로 빌드한 화면은 푸터에 빨간 글씨로 "목업 데이터로 빌드한 화면"이 붙는다.

## 구조

```
src/
  content/site.ts        Notion에 없는 값: 창립 연도, 모집 정보, 연락처, 인트로 좌표·배율
  lib/data/              데이터 진입점(db.ts / mock.ts), 행 검증
  lib/content.ts         정렬·묶음·통계·이름 연결
  lib/image.ts           R2 srcset(480/960/1600)
  components/            Header, TabBar, Footer, ScrollIntro, 카드, Picture, EmptyState, FilterControl(React)
  scripts/               intro.ts(GSAP), reveal.ts, header-tone.ts
  styles/                tokens.json(디자인 시스템 원본) → tokens.css(생성), global.css(Tailwind v4 @theme)
public/intro/            인트로 사진 4장 + 달 고해상도 2장
```

- 디자인 토큰: `tokens.json`을 고친 뒤 `pnpm --filter @luna/web tokens`로 `tokens.css`를 다시 만든다.
- 이미지 규칙(동기화 작업과 약속): DB `image_key` = `members/<sha256>` 같은 접두어, 파일은 `<key>-480|960|1600.webp`, 너비·높이는 1600 이하로 줄인 최대본 크기.

## 스크롤 인트로

`ScrollIntro.astro` + `scripts/intro.ts`. 400svh 구역 안의 sticky 무대에서 진행률 p 하나로 계산한다.

| p         | 일                                                                                      |
| --------- | --------------------------------------------------------------------------------------- |
| 0–0.06    | "스크롤해서 달에게 다가가기" 사라짐                                                     |
| 0.06–0.44 | 하늘이 달 중심으로 지수 확대(데스크톱 2.4배, 모바일 1.7배)하고 멈춤. 달이 화면 가운데로 |
| 0.20–0.38 | 도시가 더 빠르게 커지며 사라짐(시차)                                                    |
| 0.24–0.46 | 달 둘레 라벤더 빛, 달 바깥이 브랜드 배경으로 어두워짐                                   |
| 0.44–0.58 | 사진이 어두워지고 같은 자리·같은 크기에서 로고가 떠오름                                 |
| 0.58–0.68 | 로고가 제 크기로                                                                        |
| 0.68–0.80 | 로고 곡선 안쪽에서 "LUNA"가 옆으로 나옴(살짝 넘쳤다 돌아오는 back.out)                  |
| 0.78–0.88 | "IT SOCIAL VENTURE · SINCE …" + "세상을 비추는 달, LUNA"(h1)                            |
| 0.94–1.00 | 묶음이 위로 빠지고 상단 로고 등장                                                       |

- 움직임은 transform·opacity만. 레이아웃 값(달 크기, 로고 위치)은 크기가 바뀔 때만 잰다.
- `prefers-reduced-motion`, JS 꺼짐, GSAP 로드 실패 → 100svh 정적 최종 화면. 움직임 줄이기면 GSAP을 아예 받지 않는다.
- 사진: Unsplash(`public/intro/README.md`). `site.ts`의 `introScene.usePhotos`를 끄면 같은 좌표의 CSS 임시 하늘·달을 그린다.
- 달 고해상도: 사진 전체를 키우면 용량이 커지므로 달 부분(400×400)만 잘라 Real-ESRGAN x4plus(BSD-3)로 4배 키운 뒤 1200px WebP로 저장해 하늘 레이어의 달 위에 겹쳤다. 하늘과 함께 커지므로 확대해도 선명하다.

## 예외 처리

| 상황                       | 동작                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| 없는 주소                  | `404.astro`. Cloudflare가 404 상태로 돌려준다(`wrangler.jsonc`의 `not_found_handling`)                    |
| DB 연결·조회 실패          | 빌드를 멈춘다. 배포가 안 되므로 이전 사이트가 그대로 남는다                                               |
| 이름이 빈 행               | 그 행만 빼고 경고를 남긴다                                                                                |
| 목록이 비었음              | 각 구역에 빈 상태 화면(EmptyState)                                                                        |
| 필터 결과 없음             | "이 직군의 멤버가 없어요" 등                                                                              |
| 사진 없음·로드 실패        | 같은 크기의 자리표시(이니셜 또는 달 아이콘)로 바뀜. 상자 크기는 미리 잡혀 있어 레이아웃이 흔들리지 않는다 |
| 인트로 스크립트 실패       | 정적 최종 화면으로 전환                                                                                   |
| 모집 정보·연락처 비어 있음 | 모집 섹션·지원하기 버튼·링크를 숨긴다                                                                     |

## 렌더링·성능

- 이미지·카드는 모두 `aspect-ratio` 상자에 들어가 사진이 늦어도 CLS가 생기지 않는다. 사진엔 `width`·`height`·`loading="lazy"`·`decoding="async"`.
- 필터는 URL 쿼리가 있으면 첫 페인트 전 인라인 스크립트가 먼저 카드를 숨긴다(섬이 깨어날 때 흔들림 없음).
- 등장 효과·헤더 전환·탭 바·인트로는 transform·opacity만 바꾼다. 헤더 유리 배경은 별도 층의 opacity로 전환한다.
- JS(gzip): 홈 약 47KB(GSAP 코어 27 + ScrollTrigger 17 + 인트로 2 + 기타). 멤버·프로젝트·수상은 React 섬 때문에 약 70KB.
- Pretendard는 유니코드 범위별 서브셋 woff2를 셀프 호스팅한다. 화면에 쓰인 글자 범위만 받고, Apple 기기는 시스템 서체가 먼저 잡혀 받지 않는다.

## Biome

루트 `biome check .`가 이 패키지도 검사한다. `apps/web/biome.json`은 Tailwind v4 문법(`@theme`)을 읽도록 CSS 파서 옵션만 켠다.
`.astro` 파일은 Biome이 프런트매터(맨 위 `---` 사이 TS)만 검사·정리하고, 아래 HTML 템플릿과 `<style>`은 건드리지 않는다(Biome 2.6의 Astro 지원 범위). 템플릿 오류는 `astro check`(typecheck)가 잡는다.

## 디자인 초안에서 바꾼 점(UX)

1. **인트로 타임라인**: 화면 전체가 달빛으로 하얗게 덮이는 단계를 뺐다. 사용자 요청에 따라 중간 배율에서 멈추고 달이 그 자리에서 로고로 바뀐 뒤 "LUNA"가 옆으로 나온다. 하얀 화면이 사라져 헤더 글자가 묻히는 문제도 같이 없어졌다.
2. **헤더 글자색 자동 전환**: 초안은 홈 헤더가 항상 흰 글자라 밝은 구역에서 안 보였다. 헤더 아래가 어두운 구역이면 흰 글자, 밝은 구역이면 유리 막대 + 어두운 글자로 바뀐다.
3. **보조 글자색**: 디자인 시스템 `labels-secondary`는 라이트 배경 대비 3.4:1이라 본문 기준(4.5:1)에 못 미친다. 같은 토큰의 고대비 값(`#3c3c43cc`)을 썼다.
4. **"지원 안내" 버튼**: 모집 정보가 비어 모집 섹션이 숨으면 FAQ로 이동한다(빈 앵커로 가지 않게).
5. **헤더 "지원하기"**: 모집 링크(외부)로 바로 가고 새 창임을 스크린리더에 알린다. 링크가 없으면 숨기되 탭이 가운데에 오도록 같은 폭을 비워 둔다.
6. **멤버 그리드**: 좁은 화면에서 한 줄 1장 대신 2장. 카드가 세로로 너무 길어지지 않고 한 화면에 더 많은 얼굴이 보인다.
7. **수상 멤버 칩**: 이름이 정확히 같은 멤버가 한 명일 때만 멤버 카드로 연결(동명이인 오연결 방지). 연결된 칩은 보라 글자로 구분.
8. **수상 목록(홈)**: 각 줄이 해당 연도로 필터된 수상 페이지로 이동.
9. **필터**: 선택 결과 수를 스크린리더에 알리고, 결과가 없으면 빈 상태를 보인다. 옵션이 1개 이하면 필터를 숨긴다.
10. **모바일 인트로 안내 문구**: 하단 탭 바에 가리지 않도록 위로 올리고 도시 불빛 위에서도 읽히게 그림자를 줬다.
11. **건너뛰기 링크**: 키보드 사용자를 위한 "본문으로 건너뛰기"를 추가했다.
